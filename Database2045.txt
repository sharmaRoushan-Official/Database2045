> Types of Databases
------------------------------
A database can be classified according to the data model or the way in which data is organized.
----------
Important database Models/types:

1. Hierarchical Database
2. Network database
3. Relational Database
4. Object-Oriented Database
5. Object-Relational Database
6. NoSQL Database

------------------------------------------------------------------------
1. Hierarchical Database
> A hierarchical database organizes data in tree-like structure.

Parent
   |
   +----Child
------------------------------

Hierarchical=Tree Structure
-------------------------------------------------------------------------

2. Network database
> A network database organizes data as interconnected records and supports multiple relationship among records.

	Student
	/    \
       /      \
     Course   Teacher
---------------------------------------------------------------------------------
Network Database = Interconnected Records
-------------------------------------------------------------------------------

3. Relational Database
-----------------------
A relational database organizes data into tables(relations) consisting rows and columns.

Student_id 	Name 	Age	course_id
101		Vikash	25	c01
102		Priya	30	c02
--------------------------------------------------------------

Key-Features
> Data stored in tables
> Rows
> Columns
> Primary keys
> Foreign keys
> Relationships
	1. One to one
	2. One to many
	3. Many to Many
> SQL Commonly used for Querying
------------------------------------------------
Example of RDBMS:
> MySQL
> PogreSQL
> Oracal Database
> Microsoft SQL Server
> SQLite

Notes:

Relational Database -  Database Model

4. Object-Oriented Database
-----------------------------------
An object-oriented database stored data in the form of objects. Similar to object-oriented programming.

Example:

Student Object
 |
 +-----name = Vikash
 +-----age = 25
 +-----course = B.Tech
-------------------------------------------------------------------
class Student:
	def __init__(self,name,age,course):
		self.name = name
		self.age = age
		self.course = course

obj1 = Student("Vikash",25,"B.Tech")
------------------------------------------------------------------------------
Notes:

Object-Oriented Database = Data represented as Objects

6. NoSQL Database
-------------------------------------

NoSQL is broad category of database that uses data models other than, or beyond the traditional relational-table model.

Common NoSQL models include:
1. Key-value
2. Document based database
3. Column-Family
4. Graph

---------------------------------------------------------
we found multiple result with regular expression
---------------------------------------------
$ - Dollar - Matching Last Character
[]- Bracket - Between
^ - Caret - starts
| - PIPE - Multiple Values
----------------------------------------------------

|	Sign	| 	pattern	|	Description	|
---------------------------------------------------------------------
| ^ caret	|	"^ra"	| Starts from ra	|
------------------------------------------------------------------------
|[...]		| 	"[rms]"	| Any character listed between square brackets.
-------------------------------------------------------------------------------------
|$		|	"an$"	| an in the last characters.
------------------------------------------------------------------------------
|^[...]		| 	"^[rms]"| starts character from r, m, s
----------------------------------------------------------------------------
| [a-z]		|	"[a-z]e"| Match with in the range ae,be,ce,de,fe,ge,
-------------------------------------------------------------------------------------
|p1|p2|p3|	|	"tom|harry|john"| matches any of the patterns p1,p2,p3

---------------------------------------
select column1, column2, column3,column4.......

>> JOINS in Database
------------------------------------------
1. What is JOIN?

A JOIN in MySQL is used to combine data from two or more tables based on a related column between those tables.

--------------------------------------------------------------------------------
>> Types of JOIN

1. INNER JOIN
2. LEFT JOIN
3. RIGHT JOIN
4. FULL OUTER JOIN
5. CROSS JOIN

----------------------------------------------------------------------------
1. INNER JOIN
---------------------
INNER JOIN RETURNS ONLY THOSE RECORDS WHERE THERE IS A MATCHING VALUE IN BOTH TABLES.


mysql> select students.student_id,students.student_name,students.city,students.course_id,courses.course_name,courses.fees
    -> from students
    -> inner join courses
    -> on students.course_id = courses.course_id;
+------------+--------------+-------------+-----------+-------------+-------+
| student_id | student_name | city        | course_id | course_name | fees  |

|          3 | Neha         | Dehradun    |       101 | Python      | 15000 |

|          4 | Priya        | NOIDA       |       103 | MySQL       | 12000 |
+------------+--------------+-------------+-----------+-------------+-------+
4 rows in set (0.00 sec)

----------------------------------------------------------------------------------------------
2. LEFT JOIN
-----------------------------------------------------
Retunes all records from the left table and matching records from the right table.

-------------------------------------------------------------------------------------

mysql> select s.student_name,c.course_name,c.fees from students s
    -> left join courses c
    -> on s.course_id = c.course_id;

Here, Rahul is included because students is the left table.
-------------------------------------------------------------------------------------------------------
Remember:
-----------------
LEFT JOIN
	|
ALL RECORDS FROM LEFT TABLE
	|
MATCHING RECORDS FROM RIGHT TABLE.

>> MYSQL ORDER BY WITH HAVING CLAUSE
---------------------------------------------------------------------
1. ORDER BY
---------------
ORDER BY IS USED TO SORT THE RESULT IN ASCENDING OR DESCENDING ORDER.
---------------------------------------------------------------------------------
SYNTAX:
-----
SELECT COLUMN1,COLUMN2, AGGRATE_FUNCTION(COLUMN_NAME) 
FROM TABLE_NAME
GROUP BY COLUMN_NAME
ORDER BY COLUMN_NAME;
-------------------------------------------------------------

SELECT COLUMN1,COLUMN2, AGGRATE_FUNCTION(COLUMN_NAME) 
FROM TABLE_NAME
GROUP BY COLUMN_NAME
ORDER BY COLUMN_NAME ASC;
--------------------------------------------


SELECT COLUMN1,COLUMN2, AGGRATE_FUNCTION(COLUMN_NAME) 
FROM TABLE_NAME
GROUP BY COLUMN_NAME
ORDER BY COLUMN_NAME DESC;
---------------------------------------------------------------------------------------------
mysql> SELECT COURSE_ID, COUNT(*) AS TOTAL_STUDENTS
    -> FROM STUDENTS
    -> GROUP BY COURSE_ID
    -> ORDER BY TOTAL_STUDENTS DESC;
+-----------+----------------+
| COURSE_ID | TOTAL_STUDENTS |
+-----------+----------------+
|       101 |              2 |
|      NULL |              1 |
|       102 |              1 |
|       103 |              1 |
+-----------+----------------+
4 rows in set (0.00 sec)
----------------------------------------------------------------------------------------------------------------
2. HAVING CLAUSE
---------------------------------------------------------------------------------------------------------
HAVING IS USED TO FILTER GROUPD RECORDS AFTER GROUP BY.

IT IS COMMONLY USED WITH AGGRATE FUNCTION SUCH AS:

1). COUNT()
2. SUM()
3. AVG()
4. MIN()
5. MAX()
----------------------------------------------------------------------------------------
Q. SHOW ONLY THOSE COURSE_ID HAVING MORE THAN 1 STUDENT.
-----------------------------------------------
mysql> SELECT COURSE_ID, COUNT(*) AS TOTAL_STUDENTS
    -> FROM STUDENTS
    -> GROUP BY COURSE_ID
    -> HAVING COUNT(*)>1;
+-----------+----------------+
| COURSE_ID | TOTAL_STUDENTS |
+-----------+----------------+
|       101 |              2 |
+-----------+----------------+
1 row in set (0.00 sec)

--------------------------------------------------------------------------------------

3. HAVING + ORDER BY 
-------------------------------------------------------------
WE CAN USE BOTH TOGETER
-------------------------------------------------------------------------------------------------

mysql> SELECT COURSE_ID, COUNT(*) AS TOTAL_STUDENTS
    -> FROM STUDENTS
    -> GROUP BY COURSE_ID
    -> HAVING COUNT(*)>1
    -> ORDER BY TOTAL_STUDENTS;
+-----------+----------------+
| COURSE_ID | TOTAL_STUDENTS |
+-----------+----------------+
|       101 |              2 |
+-----------+----------------+
1 row in set (0.00 sec)

--------------------------------------------------------------
>> EXECUTION ORDER
----------------------------------------------------
	FROM
	  |
	GROUP BY
	  |
	HAVING
	  |
	ORDER BY
----------------------------------------------------------------------------------------------------------------------
HAVING FILTERS THE GROUPD DATA, WHILE
ORDER BY SHORTS THE FINAL RESULT
--------------------------------------------------------------------------------------------------------------------

NOTES
---------------------
1. JOIN -- COMBINES STUDENTS AND COURSES
2. GROUP BY -- GROUPS STUDENTS ACCORDING TO COURSES
3. HAVING ---> KEEPS COURSES HAVING AT LEAST 1 STUDENT
4. ORDER BY --> SORTS COURSES BY STUDENTS COUNT FROM HIGHEST TO LOWEST 
---------------------------------------------------------------------------------------------------------------------

WHERE VS HAVING

WHERE 			| 	HAVING
---------------------------------------------------------------
FILTER INDIVIDUAL ROWS	|	FILTER GROUPS
------------------------------------------------------------------------
USED BEFORE GROUP BY	| USED AFTER GROUP BY
----------------------------------------------------------------------------------
WHERE CITY == "NOIDA"	| HAVING COUNT(*) > 1;
----------------------------------------------------------------------------------


COMPLETE SYNTAX

SELECT COLUMN,
AGGRIGATE_FUCTION(COLUMN)
FROM TABLE
WHERE CONDITION
GROUP BY COLUMN
HAVING AGGRIGATE_CONDITION
ORDER BY COLUMN ASC/DESC;
------------------------------------------------------------------------------------------------------------------------------

WHERE --> FILTER ROWS
GROUP BY --> CREATE GROUPS
HAVING ---> FILTER GRUPS
ORDER BY ---> SORT RESULT

>> SUBQUERY WITH EXISTS AND NOT EXITS 
------------------------------------------------------------------------------------------------------------------------------------------------------

1. WHAT IS A SUBQUERY?
--------------------------------------------------
A SUBQUERY IS A QUERY WRITTEN INSISE ANOTHER SQL QUERY. THE INNERY QUERY IS CALLED SUBQUERY/CHILD QUERY, AND THE OUTER QUERY IS THE MAIN/PARENT QUERY.

---------------------------------------------
BASIC STRUCTURE:
-----------------------------
SELECT COLUMN
FROM TABLE1
WHERE COLUMN IN(
	SELECT COLUMN2
	FROM TABLE 2
);
-----------------------------------------------------------------------------------------------
2. EXISTS
--------------------
EXISTS IS USED TO CHECK WHERE A SUBQUERY RETURNS AT LEAST ONE ROW.

> IF THE SUBQUERY RETURN ONE OR MORE ROWS ---> EXISTS IS TRUE.

> IF THE SUBQUERY RETURNS ZERO ROWS --> EXISTS IS FALSE.

-----------------------------------------------------------------------------
SYNTAX:

SELECT COLUMNS
FROM TABLE 1
WHERE EXISTS(
	SELECT 1
	FROM TABLE2
	WHERE CONDITION
);
----------------------------------------------------------------------------

SELECT 1 IS COMMONLY USED BECAUSE WE ONLY NEED TO CHECK WHETHER A MACHING ROW EXISTS.


mysql> select course_id,course_name from courses1 c
    -> where exists(select 1 from students s where s.course_id = c.course_id);

+-----------+-------------+

|       103 | MySQL       |
+-----------+-------------+
3 rows in set (0.00 sec)

--------------------------------------------------------------------------------------------

3. NOT EXISTS
----------------------------------------

NOT EXISTS IS USED TO CHECK WHEATHER A SUBQUERY DOES NOT RETURN ANY ROW.

MATCHING COLUMN ---> NOT EXISTS = FALSE

NOT MACHTING COLUMN --> NOT EXISTS = TRUE
-----------------------------------------------------------------------------------------

6. EXISTS VS NOT EXISTS
-------------------------------------------------

|EXITS				| 	NOT EXITS
------------------------------------------------------------------------------
1). CHECK WHEATHER A ROW EXISTS	|CHECK WHEATER A ROW DO NTO EXISTS.
-----------------------------------------------------------------------------------
2). RETURN TRUE IF MATCH EXISTS	|RETURN TURE IF MATCH DO NOT EXITS

3). USED TO FIND RELATED RECORDS|USED TO FIND UNRELATED/MISRECORDS

>> MYSQL UNION AND UNION ALL
-----------------------------------------------------------------------------------------------

>> 1. WHAT IS UNION?

UNION IS USED TO COMBINE THE RESULT OF TWO OR MORE SELECT QUERIES INTO A SINGLE RESULT AND REMOVE DUPLICATE ROWS.
-----------------------------------------------------------------------------------------------------

SYNTAX:

SELECT COLUMN1, COLUMN2 FROM TABLE 1
UNION
SELECT COLUMN1, COLUMN2 FROM TABLE2
--------------------------------------------------------------------------------------------
IMPORTANT RULES

FOR UNION ONLY:
1. BOTH SELECT STATEMENETS MUST HAVE SAME NUMBER OF COLUMNS.
2. CORRESPONGIND COLUMNS SHOULD HAVE COMPITABLE DATA TYPES.
3. THE COLUMN NAME IN THE FINAL RESULT COME FROM THE FIRST SELECT.
4. DUPLICATE ROWS ARE AUTOMATCALLY REMOVED.
--------------------------------------------------------------------------------------------------------

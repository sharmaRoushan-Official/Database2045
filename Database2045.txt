> Types of Databases
------------------------------
A database can be classified according to the data model or the way in which data is organized.
----------
Important database Models/types:

1. Hierarchical Database
2. Network database
3. Relational Database
4. Object-Oriented Database
5. Object-Relational Database
6. NoSQL Database

------------------------------------------------------------------------
1. Hierarchical Database
> A hierarchical database organizes data in tree-like structure.

Parent
   |
   +----Child
------------------------------

Hierarchical=Tree Structure
-------------------------------------------------------------------------

2. Network database
> A network database organizes data as interconnected records and supports multiple relationship among records.

	Student
	/    \
       /      \
     Course   Teacher
---------------------------------------------------------------------------------
Network Database = Interconnected Records
-------------------------------------------------------------------------------

3. Relational Database
-----------------------
A relational database organizes data into tables(relations) consisting rows and columns.

Student_id 	Name 	Age	course_id
101		Vikash	25	c01
102		Priya	30	c02
--------------------------------------------------------------

Key-Features
> Data stored in tables
> Rows
> Columns
> Primary keys
> Foreign keys
> Relationships
	1. One to one
	2. One to many
	3. Many to Many
> SQL Commonly used for Querying
------------------------------------------------
Example of RDBMS:
> MySQL
> PogreSQL
> Oracal Database
> Microsoft SQL Server
> SQLite
------------------------------------------------------------------

Notes:

Relational Database -  Database Model

4. Object-Oriented Database
-----------------------------------
An object-oriented database stored data in the form of objects. Similar to object-oriented programming.

Example:

Student Object
 |
 +-----name = Vikash
 +-----age = 25
 +-----course = B.Tech
-------------------------------------------------------------------
class Student:
	def __init__(self,name,age,course):
		self.name = name
		self.age = age
		self.course = course

obj1 = Student("Vikash",25,"B.Tech")
------------------------------------------------------------------------------
Notes:

Object-Oriented Database = Data represented as Objects
---------------------------------------------------------------------------------------

5. Object-Relational Database
-----------------------
An object-relational database combines the relation model with selected object-oriented features.

Content:

Relational Model
	+
Object-Oriented Features
	|
Object-Relational Database
---------------------------------------------------------------------
PostgreSQL supports object-relational features.

6. NoSQL Database
-------------------------------------

NoSQL is broad category of database that uses data models other than, or beyond the traditional relational-table model.

Common NoSQL models include:
1. Key-value
2. Document based database
3. Column-Family
4. Graph
------------------------------------------------------
